Obtenir mon code parrainage

Complétez les étapes ci-dessous pour recevoir par e-mail votre code de parrainage BoursoBank et préparer votre dossier en toute sérénité.

Important — aucune pièce ne doit être envoyée par e-mail

Ne joignez jamais vos justificatifs (pièce d’identité, RIB, justificatif de domicile, etc.) à vos messages. Conservez-les en lieu sûr et téléchargez-les uniquement lorsque vous serez redirigé vers la procédure officielle d’ouverture de compte BoursoBank ; c’est à ce moment que votre code de parrainage vous sera demandé.

Bourso-parrainage est un site indépendant de BoursoBank : nous ne vous demanderons jamais vos coordonnées personnelles sensibles par mail. Si vous recevez une demande contradictoire, ne répondez pas et contactez-nous uniquement via l’adresse officielle.

Message de sécurité – gardez vos documents confidentiels

Nous avançons à vos côtés : envoyez-nous un e-mail, recevez votre code de parrainage par retour de mail, préparez votre dossier puis ouvrez votre compte BoursoBank avec toutes les pièces réunies.

Prévenez-nous
