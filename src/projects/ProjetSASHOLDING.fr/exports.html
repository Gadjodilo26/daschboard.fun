Exports & sauvegardes

Conservez vos hypothèses, générez un PDF et archivez vos scénarios JSON pour itérer ou partager.

Pourquoi exporter ?

  • Chaque fichier JSON contient toutes les hypothèses + le suivi de frais.
  • Tu peux en conserver plusieurs versions (ex : scénario optimiste / prudent).
  • Ces fichiers sont lisibles et ré-importables depuis cette même page.

Sauvegarde auto

  • Le bouton “Sauvegarde auto” écrit les données en local (atelier-entreprendre).
  • Désactive-le avant d’importer un scénario pour éviter d’écraser ton brouillon.
  • Pour repartir de zéro, utilise “Réinitialiser” (les fichiers JSON restent intacts).

Exporter

1. Clique “Exporter le scénario (JSON)”.
2. Range le fichier dans ton dossier projet.
3. (Optionnel) Imprime le PDF pour ton banquier.

Importer

1. Clique “Importer un scénario”.
2. Choisis un JSON sauvegardé.
3. Les pages se rechargent avec ce scénario.
