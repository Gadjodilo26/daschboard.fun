Mode d’emploi RMS Suite

Comprendre, structurer et sécuriser vos documents hors ligne

Cette page détaille la méthode recommandée pour exploiter pleinement RMS Suite : création du dossier local rms-suite, gestion des imports/exports JSON et circulation des données entre les modules.

Commencer un devis Émettre une facture

1. Principe général

RMS Suite fonctionne entièrement côté navigateur et ne stocke rien automatiquement. Toutes vos données restent sur votre machine, afin de garantir la confidentialité et de permettre un usage hors connexion. Les formulaires (émetteur, clients, lignes d’articles) peuvent être exportés sous forme de fichiers JSON, que vous organisez ensuite dans votre dossier rms-suite.

  • Autonomie totale : aucune base de données, pas de compte à créer.
  • Interopérabilité : les fichiers JSON sont réimportables dans chaque module (devis, factures, cartes).
  • Traçabilité : chaque export contient l’état complet du document au moment de la sauvegarde.

2. Créer et organiser le dossier rms-suite

Pour garder vos documents en ordre, créez un dossier dédié sur votre poste (ordinateur, clé USB, drive synchronisé, etc.) :

Le fichier rms-suite-starter.zip sera enregistré dans votre dossier Téléchargements. Décompressez-le puis déplacez le dossier rms-suite sur votre Bureau ou dans l’emplacement de votre choix pour avoir vos exports sous la main.

Structure recommandée

rms-suite/
├── profils/
│   └── societe-principale.company.json
├── devis/
│   └── DEV-20240515-045.quote.json
├── factures/
│   └── FAC-20240530-012.invoice.json
├── projets/
│   └── projet-horizon.project.json
└── cartes/
    └── carte-camille.card.json

Vous pouvez bien sûr adapter cette structure à vos besoins. L’important est de conserver un nommage explicite (numéro de devis/facture, client, date) et de ne pas mélanger les types de fichiers.

3. Comprendre les exports JSON

Chaque module propose un bouton Exporter (format JSON). Ce fichier contient :

  • les coordonnées de l’émetteur (raison sociale, mentions légales, logo encodé) ;
  • les données propres au document (client, articles, options de calcul, conditions) ;
  • le type de fichier via la clé kind ("companyProfile", "project", "quote", "invoice", "card").

Au moment de l’import, RMS Suite détecte automatiquement ce type et route le contenu vers le formulaire concerné. Par exemple :

  • Importer un .company.json recharge le profil émetteur sur la landing et dans chaque module.
  • Importer un .project.json ajoute les clients/lignes dans les formulaires Devis/Facture.
  • Les devis (.quote.json) peuvent être réutilisés tels quels pour générer une facture en conservant la même structure d’articles.

Astuce : ouvrez les fichiers JSON avec un éditeur de texte pour vérifier leur contenu ou créer des variantes rapides.

4. Workflow conseillé

  1. Renseignez votre profil entreprise sur la landing, puis exportez un fichier .company.json que vous placerez dans rms-suite/profils/.
  2. Préparez vos projets récurrents (client + prestations) via la section “Projets & clients” de la landing, puis exportez un .project.json.
  3. Dans le module Devis : importez le profil et/ou le projet, complétez les informations restantes, puis exportez le devis final (.quote.json) et imprimez le PDF.
  4. Dans le module Factures : importez le devis ou le projet pour récupérer les lignes, ajustez les dates et conditions, puis exportez la facture (.invoice.json) et imprimez.
  5. Dans le module Cartes : importez le profil entreprise pour récupérer logo, site web et coordonnées, puis exportez la carte en JSON et en image PNG.

Pensez à versionner vos documents (par exemple en ajoutant -v2, -v3 au nom du fichier) et à conserver les exports JSON en parallèle des PDF imprimés.

5. Utilisation hors ligne & sécurité

  • Mode hors connexion : une fois la page chargée, vous pouvez couper Internet. Toutes les opérations (saisie, calculs, impression) fonctionnent localement.
  • Sauvegarde de vos données : RMS Suite n’écrit rien sur votre disque tant que vous n’utilisez pas l’export. Il est donc indispensable d’enregistrer régulièrement vos fichiers JSON.
  • Logo et QR code : les images sont intégrées dans les exports (base64). Le lecteur de QR code doit être capable de lire des liens HTTPS uniquement.
  • Respect RGPD : en conservant vos fichiers localement, vous contrôlez les données personnelles de vos clients.

6. Questions fréquentes

Le dossier rms-suite est-il obligatoire ?
Vous pouvez utiliser un autre dossier, mais ce nom facilite la reconnaissance automatique lorsque vous ouvrez un répertoire via la section “Ressources” de la landing.
Puis-je partager mes modèles avec un collègue ?
Oui, copiez simplement les fichiers JSON sur une clé USB ou un espace partagé. Ils pourront être importés sur un autre poste.
Comment conserver une trace de mes documents ?
Pour chaque devis/facture, conservez à la fois le fichier JSON (permet de repartir d’un brouillon) et le PDF généré via l’impression navigateur.
Les exports JSON sont-ils compatibles avec d’autres outils ?
Ils suivent une structure simple (clef kind et objet data). Vous pouvez créer vos propres scripts pour les intégrer dans un ERP, un tableur ou un logiciel de comptabilité.
