# linkplace.fr Prototype

Cette archive contient le prototype du site **linkplace.fr**, conçu pour s'intégrer dans la suite LinkPlace :

- **linkplace.fun** – agrégateur d’URLs utiles  
- **linkplace.store** – catalogue de produits  

## Structure du projet

- `index.html` : page principale  
- `style.css` : fichier de styles global, basé sur SMACSS/BEM et variables CSS  
- `img/`           : dossier pour les logos et images (à compléter)  
- `js/`            : dossier pour scripts personnalisés (à compléter)  

## Points clés

- **Thème visuel harmonisé** : palette, typographie et composants réutilisables  
- **Responsive design** : layout fluide, grille flexible et media queries  
- **Components modulaires** : navigation, header, cards, boutons, footer  
- **Navigation intuitive** : liens vers les domaines LinkPlace suite  

## Installation

1. Dézippez l’archive  
2. Placez le contenu sur votre serveur web public (`public_html` ou équivalent)  
3. Ajoutez vos assets (`img/`, `js/`)  
4. Ouvrez `index.html` dans un navigateur
